# 강의 조교 (AI 에이전트)

확정 전사와 실험 점수를 바탕으로 실시간 제안을 만들고, 선택적으로 올린 강의 자료(PDF·PPTX)를 활용해 자료 제안과 수업 후 피드백을 만드는 모듈입니다. 모든 입출력은 통합부(`IntegrationService`)의 공통 계약 이벤트로 주고받습니다. 제안과 피드백은 참고용 초안이며, 최종 판단은 교수자가 합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `materials.py` | PDF(pypdf)·PPTX(python-pptx, 슬라이드 노트 포함)를 페이지 단위 텍스트로 읽음. 구형 `.ppt`, 암호 PDF, 스캔 이미지 PDF(텍스트 없음)는 읽지 못함 |
| `retrieval.py` | 로컬 BM25 검색. 한글은 글자 2-gram으로 색인해 조사 변화(`스케줄링을/에서는`)에 덜 민감함. 수업 말투(불용어, `~습니다` 서술어)는 제외 |
| `writer.py` | 문장 작성. `LocalWriter`(기본)와 개인 키로 OpenAI·Gemini·Claude를 호출하는 작성기 |
| `assistant.py` | `LiveAssistant`(수업 중 주기 실행)와 `generate_post_session`(수업 후 실행) |

```
STT ─ transcript_final ─▶ IntegrationService ─▶ LiveAssistant ──┐
                                 ▲                 (자료 색인 검색) │
대시보드 ◀─ 스냅샷 ─────────────┤◀─ resource_suggestion ───────────┘
                                 │◀─ post_session_feedback ── generate_post_session(사후 검토)
```

## 이벤트 계약

기존 v0.1.0 세션을 읽으며, 자료 없는 제안을 구분하기 위해 팀 합의 전인 v0.2.0 확장안을 사용합니다.

- `resource_suggestion`: `title`, `description`, `source`(`document_id`, `document_name`, `page`), `evidence_event_ids`(근거 확정 전사), `status: "suggested"`. 이벤트 구간은 근거 전사 구간입니다.
- `teaching_suggestion`: ?? AI? ??? `title`, `description`, `search_query`, `origin: ai_generated`, `trigger_threshold`, `evidence_event_ids`? ?????. ???? ?? ?? ??? ??? ??? ????.
- `post_session_feedback`: `text`, `evidence_event_ids`(구간 전사와 그 구간의 자료 제안), `status: "draft"`. 구간별(기본 5분) 피드백과 수업 전체 피드백 1건(근거 없음, 구간 `0~duration_ms`)을 만듭니다.
- `analysis_status`: `component: "assistant"`로 실행·대체·종료 상태를 알립니다.
- `provenance.module`은 `assistant`입니다. `model_id/model_version`은 로컬이면 `local-bm25-ko`/`0.1.0`, 개인 API 사용 시 `제공자/모델ID`/`prompt-v1`입니다. 외부 호출이 실패해 로컬 문장을 쓴 이벤트는 로컬 값으로 기록합니다. API 키는 이벤트에 포함하지 않습니다.
- `document_id`는 파일 내용 해시로 만든 UUID입니다. 같은 자료를 수업 시작과 사후 검토에서 다시 올려도 같은 ID가 됩니다.

## 동작

**실시간 자료 제안 (`LiveAssistant`)**
- 10초 간격으로 확인하며 최근 60초 확정 전사와 15초 이내 유효한 모델 점수가 필요합니다. 점수가 설정값 이하일 때만 제안합니다. 기본 60점은 검증되지 않은 실험값이며 수업 준비 화면에서 변경할 수 있습니다.
- 외부 AI를 선택하면 업로드 자료의 유무와 관계없이 전사와 검색된 자료 후보를 사용해 조언을 만듭니다. AI가 검색어를 제안하면 한국어 위키백과 공개 검색을 시도하고 결과 제목을 AI에 전달해 보완합니다. 제목·링크만 사용하며 본문을 읽거나 내용의 정확성을 검증하지 않습니다. 검색 실패 시 AI 초안은 유지합니다. 외부 AI 미선택 또는 호출 실패 시 자료 없는 제안은 보류합니다.
- 제안 간 최소 간격은 2분이며 점수 이벤트를 중복 사용하지 않습니다. 점수와 전사 ID를 근거로 기록합니다. 사후 분석은 이 실시간 기준과 별도로 실행합니다.

`teaching_suggestion`은 `title`, `description`, `search_query`, `origin: ai_generated`, `evidence_event_ids`와 선택적인 `trigger_threshold`, `material_sources`, `external_sources`를 포함합니다. 실시간 제안에는 임계값과 점수 근거를 남기고 사후 제안은 전사 구간을 근거로 합니다. 검색 결과는 검증된 출처가 아닙니다.
- 세션이 종료되면 스스로 멈춥니다. 조교 오류는 `assistant: unavailable`로 알리며, 수업 세션과 다른 모듈은 계속 동작합니다.

**사후 피드백·자료 제안 (`generate_post_session`)**
- 전사가 있는 5분 구간 중 유효한 실험 점수가 설정값 이하인 구간, 교수자 메모가 있는 구간, 사후 화면에서 명시적으로 선택한 검토 구간에만 시각 맞춤 제안을 추가합니다. 기존 제안이 있으면 중복 생성하지 않습니다. 점수가 없거나 관측 불가인 경우 낮은 점수로 간주하지 않습니다.
- 메모가 있는 구간은 메모를 외부 AI에 함께 전달합니다. 선택 구간이 5분 단위와 겹치면 그 5분 구간 전체가 대상이며, 전체 보기를 선택하면 전체가 대상이 될 수 있습니다. 점수 기준 기본값 60은 검증되지 않은 실험값입니다.
- 구간 피드백에는 다음 내용을 정리합니다.
  - 주요 표현, 관련 자료 페이지, 그 구간의 자료 제안
  - 교수자 메모
  - 실험 참여 점수 요약. 관측 불가를 0점으로 바꾸지 않고, 집중도·이해도로 해석하지 않습니다.
- 전체 피드백은 전사와 겹치는 설명을 찾지 못한 자료 페이지를 알려 줍니다.
- 이미 조교 피드백이 있는 세션은 중복 생성하지 않습니다. 결과는 세션 JSON에 저장되어 다시 열 때 복원됩니다.

## 개인 API 키 사용 (선택)

대시보드의 **문장 작성 방식**에서 로컬·OpenAI·Gemini·Claude 중 선택합니다. 기본값은 로컬이며 외부 서비스를 선택하면 개인 API 키와 모델 ID를 입력합니다. 사후 분석에서는 별도로 선택하고 키를 다시 입력합니다.

- **모델:** 기본 ID는 OpenAI `gpt-4o-mini`, Gemini `gemini-2.5-flash`, Claude `claude-opus-5-5`이며 변경할 수 있습니다. 계정별 사용 가능 여부와 비용은 제공자에서 확인하세요.
- **연결 확인:** 버튼을 누르면 수업 데이터 없이 구조화 응답을 요청합니다. 실제 API 호출이므로 사용량이 발생할 수 있습니다.
- **실시간 제안:** 로컬 검색으로 후보 페이지를 최대 3개 고르고, 외부 AI가 전사와 후보를 바탕으로 제안합니다. 필요한 경우 위키백과 검색 결과 제목을 참고하며 실제 내용을 확인하지는 않습니다.
- **전송 범위:** 확정 전사(실시간은 최근 60초), 교수자 메모, 후보 또는 관련 자료 페이지 텍스트, 실험 점수 요약 문장입니다. 원본 영상·음성, 얼굴 특징, 랜드마크는 보내지 않습니다. 전사에는 수업 중 언급된 이름 같은 개인정보가 들어 있을 수 있으므로, 동의 범위를 확인한 뒤 켜야 합니다.
- **외부 검색:** AI가 생성한 검색어가 한국어 위키백과로 전달됩니다. 검색어에 민감한 내용이 포함될 가능성이 있으며 검색 요청과 추가 AI 호출에 시간·비용이 들 수 있습니다.
- **자격 증명:** 키는 가려진 입력란으로 받으며 앱 실행 중 메모리에서만 사용합니다. 세션 JSON·복구 파일·로그에 키를 넣지 않습니다. 라이브와 사후 분석은 별도 입력이며, 공유 서버로 배포하면 그 서버가 입력한 키와 데이터를 처리합니다.
- **실패 처리:** 인증·네트워크 오류, 거절 또는 잘못된 응답은 로컬 결과로 대체하고 상태를 알립니다. 구조화 출력 지원과 모델 사용 권한이 필요합니다. 제공자가 처리한 데이터의 보관 정책은 각 제공자 설정에 따릅니다.

## 설치와 테스트

```powershell
video_recognition/.venv/Scripts/python.exe -m pip install -r ai_agent/requirements.txt
video_recognition/.venv/Scripts/python.exe -m unittest ai_agent.tests.test_assistant
```

`python -m unittest ai_agent.tests.test_personal_api`는 HTTP 요청을 가짜 응답으로 대체하며 외부 API를 호출하지 않습니다. 실제 키·모델의 동작과 결과 품질은 각 제공자에서 별도로 확인해야 합니다.

## 검증 상태와 한계

- **확인한 것**
  - 단위 테스트 16개를 실행했습니다. PDF·PPTX 파싱, 검색, 근거·출처 연결, 쿨다운, 사후 피드백·저장·재열기, Claude 응답 처리와 실패 시 대체를 다룹니다.
  - sherpa 한국어 샘플 음성을 실시간 속도로 STT에 넣고 PPTX 자료로 실시간 제안을 실행했습니다. 관련 문장 2개에 맞는 페이지가 제안됐고, 근거 발화가 끝난 뒤 제안까지 약 1.5초 걸렸습니다. 무관한 문장 2개에는 제안이 없었습니다.
- **확인하지 않은 것**
  - **개인 키를 사용하는 실제 API 호출은 검증하지 않았습니다.** 가짜 HTTP 응답으로 요청·오류 처리를 확인했습니다.
  - 실제 수업 자료·수업 음성에서의 제안 정확도도 아직 평가하지 않았습니다.
- **한계**
  - 키워드 기반 검색이라 같은 뜻의 다른 표현(동의어, 영어↔한국어)은 놓칠 수 있습니다.
  - 검색 기준값(`min_score`, `min_coverage`)은 임시값입니다.
  - 자료는 브라우저 세션 메모리에만 있습니다. 앱을 다시 시작하면 사후 검토 화면에서 자료를 다시 올려야 합니다.
  - 제안의 `accepted`/`dismissed` 상태 변경은 아직 계약 이벤트로 기록하지 않습니다. 화면의 숨김·메모 저장만 지원합니다.
