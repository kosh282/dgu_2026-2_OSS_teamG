# 보정 없는 사전 학습 시선 방향 모델 적용

사용자 요청: 모델을 선택해 적용한다. 화면 지점을 바라보는 보정과 자체 홍채 높이 규칙은 사용하지 않는다.
이전 WebGazer 설계는 이번 요구로 대체한다. 선택은 MobileGaze MobileOne S0 ONNX이다.
L2CS-Net 원본 ResNet50/PyTorch 방식과 비교해 기존 ONNX Runtime과 작은 배포 모델을 활용한다.

## 구현

1. `video_recognition/gaze_estimation.py`: 공식 전처리·90-bin 각도 복원, 단일 얼굴 품질 검사,
   3Hz 추론 제한, 추론 지연 표시, 정면/이탈/불명확 후보 상태와 하향 지속 확인.
   기존 FaceAnalyzer를 감싸 같은 분석 프레임과 경계를 사용한다. 특징 계약에 필드를 추가하지 않는다.
2. `download_gaze_model.py`와 선택 requirements: 명시적 실행으로 공식 배포 가중치를 받는다.
   ONNX 파일은 git에서 제외하고 출처·체크섬을 문서화한다. 새 추론 모델 외 중복 얼굴 검출기는 추가하지 않는다.
3. 독립 `engagement_model.webcam_demo --gaze`: 단일 얼굴 시선 패널을 표시한다.
   Gaussian의 머리만 숙여도 보류하는 정책을 이 옵션에서만 대체한다.
   상대 머리 Pitch≥15°와 모델 시선 Pitch≤−30°/|Yaw|<35°가 유효 추론으로 0.4초 지속되면 보류한다.
   시선 미측정은 아래 보기로 확정하지 않는다. 유효한 머리 각도로 점수를 계산하면서 시선 불명확을 표시한다.
4. 모델 각도와 머리 각도는 다르다. 시선 좌표는 카메라 기준이며 실제 모니터 안팎을 확정하지 않는다.
   정면 후보: |Yaw|≤20°, |Pitch|≤15°. 이탈 후보: |Yaw|≥35° 또는 |Pitch|≥30°.
   사이 범위는 불명확이다. 모든 임계값은 검증 전 실험값이다.

## 검증과 경계

합성 logits 전처리·복원, 품질/다중 얼굴/시간/추적 변경/속도 제한, Gaussian 기본 경로와 선택 정책을 검사한다.
실제 ONNX 가중치를 로드해 합성 영상 추론 시간을 측정한다. 카메라와 실제 정확도·Windows는 자동으로 검증됐다고 하지 않는다.
원본 영상·시선 이력·임시 개인 키를 저장하지 않는다. 기존 FeatureWindow·세션 JSON·프런트·재식별은 변경하지 않는다.
가중치 외 기존 패키지를 업그레이드하지 않는다. 커밋·푸시는 요청 전 하지 않는다.

구현·검증 완료 기록: 모델 검사 98개, 시선·재식별 검사 24개 통과(합계122).
실제 공식 ONNX 로딩/출력 이름/형상과 합성 추론 확인. 도움말·diff 공백 검사 통과.
리뷰에서 발견한 작은 얼굴의 캐시 재사용과 트랙 변경의 캐시 전이 문제를 수정했다.
실제 카메라 정확도·발열·Windows 동작은 검증하지 않았다.
