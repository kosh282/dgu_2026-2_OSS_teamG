# Gaussian 전용·상체 분석 제거 작업 계획

사용자 요청: Gaussian만 유지하고 Legacy/Huang과 상체 pose 측정은 제거한다. 기존 독립 데모의 나머지 실험 옵션은 유지한다.

- [x] Gaussian이 사용하는 입력 검증·방향 상태·시간 관리를 보존하면서 Legacy/Huang 수식·설정·비교 실행기를 제거한다.
- [x] 프런트·웹캠 데모를 Gaussian으로 통일하고 Legacy/Huang 옵션을 제거한다.
- [x] 상체 분석기·스케줄링·특징·미리보기·관련 테스트를 제거한다. 얼굴 머리 자세는 유지한다.
- [x] 메모리 FeatureWindow 버전을 experimental-0.9로 올리고 문서·테스트를 갱신한다. 저장 이벤트 계약은 유지한다.
- [x] 기존 Gaussian 출력과 비교하고 모델·프런트·영상 테스트 및 CLI 도움말을 확인한다.

미추적 사용자 파일, 세션/로그/캐시, 다른 기능은 변경하지 않는다. 커밋·푸시는 별도 요청 전까지 하지 않는다.

검증 결과: 모델 125개, 영상 실험 44개, 프런트 47개 통과. Gaussian 변경 전후 602개 출력 비교 일치. 네 실행 모듈의 --help 확인. 실제 카메라/Windows 창 캡처는 실행하지 않음. 별도 코드 검토에서 중요 회귀 없음. 기존 integration/tests 경로는 없으므로 해당 discover 명령은 실행 대상을 찾지 못했고, JSON 계약 왕복은 모델/publisher·프런트 테스트에서 확인함.
