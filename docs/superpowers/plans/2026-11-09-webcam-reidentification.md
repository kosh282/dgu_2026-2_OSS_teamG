# Mac 웹캠 재식별 실험 구현 계획

승인 범위: 단일 실행 안에서 얼굴 재등장을 임시 ID로 연결한다. 임베딩·ID·이미지는 메모리에만 유지하고 종료 시 삭제한다. 기존 점수·보정·Windows 데모·저장 계약을 바꾸지 않는다.

구현 방식: 현재 작업 폴더에서 직접 구현한다. 기존 README 변경과 미추적 파일은 보존한다. 독립 `face_reidentification.py`에 순수 벡터 비교와 선택적 InsightFace 어댑터를 둔다. Mac 데모의 `--reidentify`에서만 활성화하고 표시 복사본에만 ID를 그린다. 기본 실행은 추가 의존성이 필요 없다.

- [x] 합성 벡터로 재등장·다른 얼굴·애매한 후보·결측·만료·종료 초기화 테스트를 작성하고 실패를 확인한다.
- [x] 연속 3회 확인, 품질 gate, 최대 120초 미관측 보관, 최대 32개 템플릿의 메모리 갤러리를 구현한다. 임계값은 검증 전 실험 설정으로 문서화한다.
- [x] InsightFace CPU 추론을 초당 최대 2회 실행한다. 복수 얼굴은 이번 단일 얼굴 실험에서 보류한다. 모델은 무시되는 `.venv/reid-cache`에만 둔다.
- [x] Mac 데모 옵션·화면 표시·종료 초기화를 연결하고 ID/임베딩이 결과 사전 및 로그로 유입되지 않는지 확인한다.
- [x] 설치·모델 초기화·도움말·관련 회귀 테스트를 실행하고 실제 카메라 검증과 구분해 보고한다.

판단: 신규 등록도 연속 관측으로 확인하며, 두 후보가 비슷하면 보류한다. 얼굴이 사라진 동안의 점수나 보정은 복원하지 않는다. InsightFace 모델은 비상업 연구용이며 실행 옵션을 통해 명시적으로 활성화한다. 카메라는 자동으로 열지 않는다.

## 검증 기록

- `python -m unittest experimental_vision.test_reidentification engagement_model.tests.test_model engagement_model.tests.test_runtime`: 35개 통과.
- `python -m video_recognition.webcam_test_mac --help`: 재식별 옵션 확인.
- `pip check`: 의존성 충돌 없음.
- InsightFace 2.1 / ONNX Runtime 1.31.1 설치, buffalo_l CPU 로딩과 합성 영상의 검출·512차원 특징 추론 성공.
- 기존 영상 테스트 16개 중 5개 실패(2 failure / 3 error)는 임시 디렉터리의 수정 전 HEAD에서도 동일하게 재현됨. 기존 Windows API 접근, 보정 테스트 입력, 이전 import, 중간 파일 추적 키 기대값과 관련되어 이번 범위에서 수정하지 않음.
- 실제 카메라/GUI/정확도/지연은 미검증. 커밋·푸시는 하지 않음.

리뷰 반영: 추론 대기 프레임에서도 미검출/복수 얼굴이 연속 확인을 끊도록 수정하고, 수정 전 실패·수정 후 통과하는 회귀 테스트를 추가함.

## 후속 요청: Windows 데모 지원

사용자 요청으로 `webcam_test.py`에도 동일한 `--reidentify` 옵션을 추가함. Windows 캡처는 유지하고 캡처 프레임의 표시 복사본에만 재식별을 적용함. 옵션 미지정 시 InsightFace를 초기화하지 않음. 모의 Windows 경로의 옵션 켜기/끄기·창 핸들 전달·로그 분리·종료 정리 테스트를 추가하여 수정 전 옵션 인식 실패와 수정 후 통과를 확인함. 관련 테스트 총 36개 통과. Windows 실제 장치 실행은 미검증.

## 후속 요청: 연결 유지 중 추론 중단

ID 확인 후 기존 임시 위치 추적 키로 연결을 유지하고 InsightFace 추론을 생략한다. 미검출/복수 얼굴/키 변경/1.5초 초과 관측 공백/시간 역전 시 해제하여 재확인한다. 연결 유지 시 마지막 관측 시각을 갱신해 120초 템플릿 만료가 관측 공백에만 적용되게 한다. ID·벡터 저장 경계는 유지한다. 관련 38개 테스트 통과. 실제 CPU·카메라 지연은 미측정.

## 승인한 후속 범위: 동시 다인 재식별

얼굴별 임시 위치 키와 메모리 ID를 연결한다. 갤러리 비교는 프레임 단위 일대일 할당과 후보 충돌 보류를 적용한다. 미확인 얼굴 영역에만 InsightFace를 실행하고 기존 연결은 추론 없이 유지한다. MediaPipe 경계는 분석기의 현재 프레임 메모리 속성으로 제공하며 특징/저장 사전에 추가하지 않는다. 겹침/미검출/키 변경/긴 공백 때 재확인한다. Windows/Mac 모두 지원하며 단일 얼굴 점수와 저장 계약은 유지한다. 실제 다인 카메라 검증은 별도로 필요하다.

다인 검증: `experimental_vision.test_reidentification`과 점수 모델 테스트 합계 38개 통과. 동시 ID·배열 순서 변경·한 사람 이탈/복귀·기존 얼굴 추론 생략·중복 후보·겹침·작거나 다른 위치의 검출·긴 공백·120초 초과 연속 연결·템플릿 만료·로그 분리를 합성 입력으로 확인함. 실제 다인 정확도/프레임률은 미검증.

## 단일 얼굴 등록 회귀 수정

실제 Mac 카메라 비교: 전체 영상은 얼굴 1개(검출 신뢰도 약 0.75~0.80), 15% 확장 얼굴 crop은 3회 연속 0개. 전체 영상 검출과 미확인 얼굴만 임베딩 계산하도록 수정한다. 검출 품질 하한은 실험값 0.7로 조정하고 크기/중심/IoU/일대일 대응 조건은 유지한다. 합성 회귀 입력은 crop 경로가 실패하고 전체 영상에서는 0.76 검출이 성공하는 사례를 포함한다. 실제 카메라 짧은 시험에서 연속 확인 3회 후 연결 1개 및 추론 생략을 확인했다. 다인 실측 검증은 여전히 필요하다.
