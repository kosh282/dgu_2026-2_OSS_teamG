# 교수자 라이브 세션 — Streamlit 프로토타입

Figma의 `1. 라이브 세션 (회의 옆 패널 · 화면 1/3)` 화면을 구현한 실행 가능한 프런트엔드야.

## 실행

Python 3.10 이상에서:

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에 표시되는 로컬 주소(일반적으로 `http://localhost:8501`)를 열면 돼.

## 동작하는 기능

- 큰 참여 상태 카드: 좋음(70~100), 보통(40~69), 나쁨(0~39), 분석 보류(값 없음)
- 점수 타임라인 및 관찰 신호 레인, 메모 마커
- 세션 타이머 시작/일시정지 및 새로고침
- 교수자 메모 작성·타임라인 반영
- 강의 자료 제안 표시, 메모로 저장 및 숨기기
- 이벤트 JSON 불러오기, 세션 JSON 내보내기

## 현재 제한

- 기본 표시 내용은 Figma의 예시 데이터를 바탕으로 한 데모야.
- 타이머를 시작해도 실제 영상 분석이나 STT가 자동 실행되지는 않아.
- JSON 불러오기는 `events` 배열의 `engagement_window`, `note_created`, `resource_suggestion`을 처리해. 참여 점수는 `payload.score` 또는 `payload.engagement_score`에서 읽어. 실제 팀의 세부 payload 키가 다르면 `ingest()`를 조정해야 해.
- 참여 점수 `null`은 **분석 보류**로 표시하며 0점으로 대체하지 않아.
- 예시 그래프의 관찰 신호 레인과 변화 알림 구간은 정적 목업이야. JSON에서 실시간으로 갱신하려면 추가 이벤트 필드 매핑이 필요해.
- 로컬 JSON 내보내기는 프로토타입용이며, 팀의 최종 통합 JSON 명세와 완전히 동일하다고 보장하지 않아.

## 공통 세션 JSON 확인

세션 설정에서 **공통 계약 예제 불러오기**를 누르면 합성 예시를 바로 볼 수 있다. 또는 통합부가 저장한 세션 JSON을 선택하고 **JSON 적용**을 누르면 확정 전사, 메모, 자료 출처와 분석 상태를 볼 수 있다. 참여 모델이 없어 점수가 없으면 측정 불가로 표시한다. 파일 불러오기는 실시간 영상 분석 연결이나 계약 전체의 자동 검증이 아니다. 타이머와 JSON 내보내기는 여전히 프런트 프로토타입 기능이다.

## 실시간 영상 연결 (Windows)

저장소 루트에서 영상 분석 의존성(`video_recognition/requirements-integrated.txt`)과 이 폴더의 의존성을 같은 Python 환경에 설치한 뒤 실행한다.

```powershell
video_recognition/.venv/Scripts/python.exe -m pip install -r frontend/requirements.txt
video_recognition/.venv/Scripts/python.exe -m streamlit run frontend/app.py
```

`실시간 수업 창 연결`에서 수업 제목과 창을 선택한 뒤 **창 연결**을 누른다. 이 단계는 대상 창 핸들만 보관하며 캡처·분석·타이머를 시작하지 않는다. 연결 후 라이브 세션의 **수업 시작**을 누르는 순간 다음이 같은 시각을 기준으로 시작된다.

- 공통 세션 JSON의 `session.title`과 수업 세션 시계
- 선택한 창의 MediaPipe 영상 분석과 분석 상태 이벤트
- 메모·향후 참여 모델의 `engagement_window` 이벤트를 받는 실시간 타임라인

따라서 수업 제목은 저장 JSON 및 추후 피드백·자료 제안에서 같은 수업을 가리키는 이름으로 사용된다. 수업 진행 중에는 화면 안의 **새로고침** 버튼이 비활성화되어 진행 중 세션을 실수로 다시 그리지 않는다. 수업이 끝나면 **수업 종료**를 누르고, 종료 뒤 **공통 계약 세션 JSON 저장**으로 다운로드할 수 있다.

화면의 얼굴·상체 검출 후보 수는 실제 참가자 수나 참여도 점수가 아니다. 참여 모델과 STT, 실시간 점수는 아직 연결되지 않았다. 참여 모델이 연결되면 `engagement_window`가 공통 타임라인에 자동 표시되도록 경로는 준비되어 있다. 기본 예시 그래프와 별도의 프로토타입 내보내기는 실제 분석 결과가 아니다.

### 개발자 모드

실시간 분석 중 화면 맨 아래 **개발자 도구**의 **개발자 모드 켜기**를 누르면 Windows의 별도 OpenCV 창 두 개가 열린다. 첫 창은 실제 분석기에 전달된 동일 캡처 프레임에 얼굴·상체 랜드마크를 겹친 화면이고, 두 번째 창은 얼굴 수·품질·머리 각도·보정 상태 등 현재 프레임의 특징값이다. 이 표시는 점검용이며 랜드마크 원시 좌표나 캡처 이미지를 세션 JSON으로 저장하거나 외부 전송하지 않는다.

- `V`: 랜드마크 점/상체 연결선 표시 전환
- `C`: 단일 얼굴 정면 상태를 약 3초 수집해 임시 머리 각도 기준 설정
- `Q`: 개발자 창만 숨김 (영상 분석은 계속 진행)

개발자 모드는 Windows OpenCV 창을 쓸 수 있는 로컬 환경에서만 사용한다. 분석을 끝낼 때는 대시보드의 **수업 종료**를 눌러야 한다.

## 파일

- `app.py`: Streamlit 화면 및 데모 이벤트 처리
- `requirements.txt`: 실행 패키지
- `sample_events.json`: 연결 테스트용 JSON
